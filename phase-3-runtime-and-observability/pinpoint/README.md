# Pinpoint

## 📚 학습 자료
- 공식 문서: https://pinpoint-apm.gitbook.io/pinpoint/want-a-quick-tour/overview
- 핵심 섹션: Architecture, Agent 동작

## 🎯 학습 목표
- Pinpoint의 아키텍처(Agent, Collector, Web)를 설명할 수 있다
- 트레이스 수집 원리와 샘플링 전략을 이해한다
- Call tree를 읽고 병목 구간을 식별할 수 있다

## 🔗 실무 연결
- APM 트레이스 수집 원리
- 성능 병목 분석 및 트러블슈팅

## 🛠 Hands-on

### 시작점 (미리 준비됨, 15분 이내 실행 가능)
- [ ] Pinpoint Web UI에서 한 트랜잭션 클릭 → call tree 따라가며 어디서 시간이 소요되는지 분석
- [ ] Pinpoint Agent 설정 파일(`pinpoint.config`)에서 샘플링 비율, 제외 URL 설정 확인
- [ ] 한 메서드를 의도적으로 느리게 만들어서(`Thread.sleep` 등) Pinpoint 트레이스에 어떻게 잡히는지 확인
